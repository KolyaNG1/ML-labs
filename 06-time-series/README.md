# Лабораторная 6 — анализ и прогноз временного ряда

## Цель работы

Работа с **классическим рядом** пассажирских авиаперевозок (Airline passengers): визуализация, разложение/преобразования по смыслу ноутбука и построение **прогноза** (набор методов смотрите в ячейках `ML_laba_6-TS.ipynb`).

## Файлы в этой папке

| Файл | Описание |
|------|----------|
| `ML_laba_6-TS.ipynb` | Анализ и моделирование ряда |
| `AirPassengers.csv` | Месячные данные: колонка времени и число пассажиров (используется в ноутбуке) |
| `1ECO-USD.csv` | Дополнительный CSV (курс/экономика) — **можно использовать для собственных экспериментов**; в текущем виде ноутбука опирайтесь на ячейки с `AirPassengers.csv` |

## Запуск

1. Установите `polars`, `matplotlib` и остальные пакеты из [requirements.txt](../requirements.txt) по мере импортов в ноутбуке.
2. Поместите CSV рядом с `ML_laba_6-TS.ipynb` либо поправьте пути в ячейках `pl.read_csv(...)`.

## Идеи, которые обычно встречаются в таких работах

- Стационарность, **дифференцирование**, ACF/PACF.
- Прогноз (ARIMA / экспоненциальное сглаживание / и т.д. — в зависимости от реализации в ноутбуке).

Проверьте заголовки разделов в самом `ML_laba_6-TS.ipynb` — они задают точный перечень методов.
