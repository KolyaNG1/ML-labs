# Лабораторная 7 — классификация аудио (Hugging Face + PyTorch)

## Цель работы

**Загрузка аудиодатасета** с **Hugging Face** (`datasets`), исследование структуры (в т.ч. вложенного WAV), предобработка (обрезка/паддинг, мел-спектр и др. — по коду ноутбука), обучение классификатора (в т.ч. с **CatBoost** / нейросетевыми модулями, см. импорты в ноутбуке).

## Файлы в этой папке

| Файл | Описание |
|------|----------|
| `ML_Laba_7-Audio.ipynb` | Полный pipeline: от загрузки датасета до обучения и оценки |

**Локальные WAV-файлы в репозиторий не входят:** семплы приходят из Hugging Face при выполнении ячеек. Артефакты обучения вроде `catboost_info/` лучше не коммитить (есть в [.gitignore](../.gitignore)).

## Подготовка окружения

1. Установите зависимости из [requirements.txt](../requirements.txt) — минимум: `torch`, `torchvision`, `datasets`, `huggingface-hub`, `polars`; по необходимости: `librosa`, `catboost`, `scikit-learn` и др. по `import` в ноутбуке.
2. Для **закрытых** или **gated** датасетов выполните `huggingface-cli login` (как в комментариях внутри ноутбука, если датасет требует авторизации).
3. Нужен **доступ в интернет** при первой загрузке сплитов и кэшировании.

## Примечания

- Имена файлов/сплитов в коде (например, `data/train-00000-of-00001.parquet`) должны совпадать с репозиторием датасета на Hugging Face; при смене версии датасета пути в ноутбуке могут потребовать обновления.
- Для **воспроизводимости** фиксируйте версии `datasets` и `torch` в своём окружении.
