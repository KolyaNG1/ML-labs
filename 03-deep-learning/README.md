# Лабораторная 3 — нейронная сеть на низком уровне (свои тензоры и оптимизатор)

## Цель работы

Понять устройство **автоматического дифференцирования** и оптимизатора, реализовав с нуля классы в духе PyTorch: **`Parameter`**, **Adam**, прямой и обратный проход для простой MLP-архитектуры. Затем сравнение с **классификацией** на встроенном датасете `load_digits` (sklearn).

## Файлы в этой папке

| Файл | Описание |
|------|----------|
| `ML_laba_3.ipynb` | Реализация слоёв, loss, тренировочный цикл, эксперименты на Digits |
| `data.csv` | Тот же табличный датасет, что в лабе 2, для части с регрессией «просмотры» и т.п. |

## Содержание по смыслу

- Загрузка `data.csv`, целевой признак `views`, подготовка `X` / `y`.
- Реаликация **`Parameter`**, **Adam**, обучение линейной / нелинейной модели с MSE.
- Блок с **`load_digits`**: one-hot, полносвязная сеть, `accuracy`.

## Запуск

1. Установите из [requirements.txt](../requirements.txt) пакеты `numpy`, `attrs`, `pandas`, `scikit-learn`, `matplotlib`; для `Parameter` и графа вычислений используется **NumPy** (без PyTorch).
2. Файл `data.csv` должен лежать **в той же папке**, что и `ML_laba_3.ipynb`.
