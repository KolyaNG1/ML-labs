# Лабораторная 5 — отбор признаков, кластеризация, визуализация

## Цель работы

Практика **отбора признаков** (свои реализации и `sklearn`), оценка влияния отбора на **логистическую регрессию** (SMS ham/spam), затем **кластеризация** на контролируемых и текстовых признаках и снижение размерности (**PCA**, **t-SNE**) для визуализации.

## Файлы в этой папке

| Файл | Описание |
|------|----------|
| `ML_laba_5.ipynb` | Полный цикл: SMS → bag-of-words → отбор признаков → кластеризация → 2D-визуализация |
| `SMS.tsv` | Классический датасет SMS: метки `ham` / `spam` и текст (табулированный формат) |

## Структура работы (по разделам ноутбука)

1. Пользовательские методы **выбора признаков**.
2. Библиотечные аналоги и сравнение.
3. Влияние отбора на качество **классификации** спама.
4. **Кластеризация** до и после отбора признаков; синтетические данные + текстовая матрица.
5. **PCA** и **t-SNE** для отображения в двумерное пространство.

## Запуск

1. Установите `polars`, `scikit-learn`, `numpy`, `pandas`, `matplotlib` (см. [requirements.txt](../requirements.txt)).
2. Файл `SMS.tsv` должен лежать рядом с ноутбуком: чтение через `pl.read_csv("SMS.tsv", separator='\t', ...)`.

## Зависимости

`polars`, `scikit-learn`, `numpy`, `pandas`, `matplotlib`.
